# Jira关闭复盘验证清单

## 统计边界

1. 为两个项目的同一严重等级设置不同关闭总周期（例如10天和21天），查询相同耗时的问题，确认按所属项目分别判定。
2. 修改时效标准后重新分析，确认卡片、对比图、明细一起应用新值；已保存的复盘快照保持原标准版本。
3. 验证耗时等于时限、超过时限1秒、缺少时限、缺少关闭日期和不完整历史。超期天数向上取整，按期判定不使用显示值的四舍五入结果。
4. 一条阶段超期但关闭总周期达标的问题，应算按期且允许复盘；完全未超期的问题不可复盘。
5. 多查询方案重复命中只计一次；同项目方案使用不同严重等级字段应在查询前纠正，保证统计定义一致。
6. 周/月/年、同比/环比、跨年ISO周、闰年、短月和当前半周期均检查分子、分母和样本量。基期零、空样本显示说明。
7. 关闭后重新打开、再次关闭和同一阶段多次进入，确认历史关闭事件与阶段累计时间正确。当前未关闭不应抹去早期周期末已关闭的记录。

## 复盘与权限

1. 首列为操作；筛选项目、严重等级、关闭时效、阶段、关闭日期和复盘状态；从明细进入复盘后保留列表筛选。
2. 空原因、空责任人、无分类不能保存；后台同样拒绝非法输入。供应商责任人可自由填写。
3. 保存后刷新、重新登录仍能查看；其他有查看权限的用户可查看共享记录；重复保存得到具体提示。
4. 两人同时修改同一复盘，旧修订号更新与删除均被拒绝。编辑不改写问题及标准快照。
5. 无查看权限无法访问列表；只读账号不能新增、编辑、删除；各写接口校验独立权限。字典分类选择不要求字典管理权限。
6. 切换Jira服务器后无法读取或修改其他服务器的复盘。直接请求接口无法绕过来源校验。
7. 被引用的分类无法删除；错误分类ID及其他字典的ID不能保存。删除复盘后引用计数减少。
8. 查看菜单三项分析与当前筛选后的列表一致；多阶段超期可贡献多条阶段统计，问题数量仍去重。
9. 校验CSV筛选结果、长文本转义、表格首列、移动端滚动、加载失败重试，以及PDF包含新增卡片和两张对比图。

## 本次已执行的验证范围

- Node统计回归、JavaScript语法及差异格式检查。
- SQLite从基础结构顺序执行迁移，并检查唯一约束、来源隔离、引用约束及修订号更新/删除。
- JSDOM＋模拟API交互验证：卡片/图表生成、已关闭筛选、必填校验、复盘新增/读取/修改/删除、修改后筛选项刷新和只读权限，通过且无未捕获JS异常。
- 当前环境没有.NET SDK，未执行.NET构建及真实Jira/ASP.NET联调。
- 已补充 Chromium 真浏览器验证，加载完整应用脚本与样式（模拟接口）：复盘增删改查、分类慢响应/失败/重试、取消未完成请求、保存失败保留输入、只读权限；普通/精简/已关闭三类穿透列表各121条记录，在1440×900、1280×720、1024×768、390×844、844×390窗口检查筛选、分页及可滚动布局。
- 已检查同比/环比和超期处理分析的浏览器截图；真实Jira、ASP.NET持久化联调及PDF实际打印仍需手动验证。

## 复盘交互与布局回归（本次修复）

- 复盘先显示窗口再读取分类，15秒未返回提供重试；窗口关闭后终止读取。无权限、历史不完整、未发现超期及状态加载失败均给出可见说明。
- 分类或保存失败在窗口内显示原因并保留已填内容；连续点击不重复打开或提交。
- 对比图查询条件、说明和图表具有独立间距；分析图卡片补齐内边距，长分类/责任人文本可换行。
- 当日未跟进图表在没有未关闭问题时也绑定穿透事件，点击零样本显示空明细。
- 共用穿透弹窗按可用空间布局，短窗口可滚动；列宽按标题/评论语义设置，首列操作和表头保持可访问。
- 静态资源版本已更新，避免新脚本搭配旧样式缓存。

浏览器回归脚本：`tests/jira-ui-regression.cjs`。在装有 Playwright 和 Chromium 的开发环境执行 `node tests/jira-ui-regression.cjs`。可通过 `PLAYWRIGHT_MODULE` 指定现有 Playwright 模块，通过 `CHROMIUM_EXECUTABLE_PATH` 指定浏览器；`JIRA_TEST_OUTPUT_DIR` 可选，用于保存截图。脚本启动临时静态服务，模拟业务接口，不启动.NET服务，不触发CI，不验证真实数据库写入。
