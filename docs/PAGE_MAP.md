# 页面结构

```text
仪表盘
├─ 核心指标卡
├─ 部门交付物柱状图
├─ 版本状态环形图
├─ 近6个月趋势
└─ 最近更新

交付物台账
├─ 多条件筛选
├─ 交付物列表
├─ 新增交付物
└─ 交付物详情
   ├─ 基本信息
   └─ 版本记录
      ├─ 新增版本
      ├─ 提交评审
      ├─ 退回草稿
      ├─ 正式发布
      └─ 废止

变更管理
├─ 发起变更
├─ 批准/驳回
├─ 开始实施
├─ 提交验证
└─ 关闭

基础设置
├─ 运行状态
├─ 项目/车型维护
└─ 数据库备份

字典管理
├─ 字典搜索及类型/结构/状态筛选
├─ 系统级/业务级字典信息
├─ 平级字典项维护
└─ 树形字典项维护
   ├─ 新增根节点/下级节点
   ├─ 调整上级节点
   └─ 循环层级与删除保护
```
