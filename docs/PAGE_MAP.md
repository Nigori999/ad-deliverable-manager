# 页面结构

```text
仪表盘
├─ 核心指标卡
├─ 部门交付物柱状图
├─ 版本状态环形图
├─ 近6个月趋势
└─ 最近更新

交付物台账
├─ 多条件筛选
├─ 交付物列表
├─ 新增交付物
└─ 交付物详情
   ├─ 基本信息
   └─ 版本记录
      ├─ 新增版本
      ├─ 提交评审
      ├─ 退回草稿
      ├─ 正式发布
      └─ 废止

变更管理
├─ 发起变更
├─ 批准/驳回
├─ 开始实施
├─ 提交验证
└─ 关闭

问题管理
├─ 公司问题总量与较上一统计日变化
├─ 问题存量增长趋势
├─ 部门/严重等级/来源分类占比
├─ 部门/来源/严重等级动态状态堆积排名
└─ 问题快照明细
   ├─ 录入截至统计日的存量
   ├─ 编辑/删除问题快照
   └─ 动态状态数量录入

JIRA看板
├─ 查询方案多选与统一截止日期
├─ 单项目绑定的私人组合查询方案
│  ├─ 项目表单字段搜索
│  ├─ 保存/更新/重命名/删除多个方案
│  └─ 严重等级、ECU Variant、组合条件及附加JQL
├─ 多项目独立查询、去重与汇总
├─ 指定日期状态还原
├─ 累计到达阶段漏斗图与穿透明细
├─ 问题新增/关闭趋势折线图
├─ 未关闭问题分布（严重等级／字典细分分类双环形图）
├─ 严重等级或分类联动的处理人问题堆积柱状图
├─ 当日未评论跟进总量及严重等级分布
├─ 阶段/关闭总周期超时条形图
├─ 问题关闭率（严重等级／分类双柱状图）
├─ 按期关闭率（严重等级／分类双柱状图，含时效筛选穿透）
├─ 问题处理时长分析（分类／严重等级／阶段三分区折线，独占整行）
└─ 各图表穿透明细及CSV导出

JIRA时效标准（系统管理）
├─ 当前全局Jira服务器的项目标准列表
├─ 六阶段Jira状态映射
├─ 各阶段S/A/B/C自然日时限
├─ S/A/B/C关闭总周期
└─ 新增/编辑/复制/启停/删除

基础设置
├─ Jira全局地址、服务账号和加密密码
├─ Jira连接测试
├─ 运行状态
├─ 项目/车型维护
└─ 数据库备份

字典管理
├─ 字典搜索及类型/结构/状态筛选
├─ 系统级/业务级字典信息
├─ 平级字典项维护
└─ 树形字典项维护
   ├─ 新增根节点/下级节点
   ├─ 调整上级节点
   └─ 循环层级与删除保护
```
