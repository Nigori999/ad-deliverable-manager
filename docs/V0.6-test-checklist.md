# V0.7 回归测试清单

## 一、升级、登录与用户

- [ ] 使用旧版`deliverables.db`启动，原交付物、版本和变更数据仍存在。
- [ ] 登录成功后主页面从顶部显示，不需要向下滚动。
- [ ] 管理员可新增、编辑、重置密码和删除用户。
- [ ] 当前登录账号不能删除。
- [ ] 最后一个启用管理员不能删除。

## 二、仪表盘统计说明

- [ ] 6个统计卡片标题后均显示说明图标。
- [ ] 各部门数量、版本状态、近6个月趋势、类型分布、最近更新标题后均显示说明图标。
- [ ] 鼠标悬停和键盘Tab聚焦均能显示完整统计规则。
- [ ] 说明中的状态、时间范围和排除规则与页面数字一致。

## 三、完整度分析说明

- [ ] 6个指标卡片均显示说明图标。
- [ ] 部门完整度、需求追溯、硬件覆盖、问题清单均显示说明图标。
- [ ] 元数据说明包含公共字段和类型专属字段。
- [ ] 硬件说明包含7类标准硬件名称。

## 四、交付物编码

- [ ] 台账“交付物编码”表头显示说明图标。
- [ ] 说明展示`AD-部门-类型-项目-对象-流水号`结构和示例。
- [ ] 新增交付物编码仍由系统生成且不可手工修改。
- [ ] 归档交付物后原编码不被复用。

## 五、自动版本号

- [ ] 新增交付物首个版本固定为`V1.0.0`。
- [ ] 新增版本不再显示可手工编辑的内部版本号。
- [ ] 选择修订版本：`V1.2.3 → V1.2.4`。
- [ ] 选择功能版本：`V1.2.3 → V1.3.0`。
- [ ] 选择重大版本：`V1.2.3 → V2.0.0`。
- [ ] 切换版本类型后原版本、新版本和规则说明同步刷新。
- [ ] 后端实际生成的版本号与页面预览一致。
- [ ] 已存在更高草稿版本时，以全部合法版本中的最高版本继续计算。

## 六、版本审批

- [ ] 草稿版本可提交审批。
- [ ] 审批中版本可退回或发布。
- [ ] 发布后成为当前有效版本，原当前版本变为已替代。
- [ ] 已发布或已替代版本可废止。
- [ ] 所有按钮均显示成功或明确错误提示，不返回405。

## 七、变更闭环

- [ ] 发起变更后自动记录当前有效版本为变更前版本。
- [ ] 待评估变更可批准或驳回。
- [ ] 已批准变更可开始实施。
- [ ] 实施中且未关联新版本时显示“创建变更版本”。
- [ ] 创建变更版本时可选择重大、功能、修订版本。
- [ ] 新版本创建后，变更记录显示“变更前版本→变更后版本”。
- [ ] 未创建变更版本时不能提交验证。
- [ ] 关联版本未发布时不能关闭变更。
- [ ] 关联版本发布后可以关闭变更。
- [ ] 关闭后实际完成时间被记录。

## 八、变更时间线抽屉

- [ ] 台账每行操作列显示“变更记录”。
- [ ] 点击后从右侧打开抽屉，不跳转页面。
- [ ] 时间线按更新时间由近到远展示。
- [ ] 时间线包含编号、状态、原因、内容、前后版本、发起人、责任人、审批人和时间。
- [ ] 无变更记录时显示明确空状态。
- [ ] 点击遮罩或关闭按钮可关闭抽屉。

## 九、CSV与关联关系

- [ ] 台账和变更管理可选择字段导出CSV。
- [ ] 中文Excel打开不乱码。
- [ ] 交付物关联支持新增、查看、跳转和删除。
