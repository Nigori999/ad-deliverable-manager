# V0.6 回归验证清单

## 一、升级及登录

- [ ] 使用旧版`deliverables.db`启动，新表自动创建且原数据仍存在。
- [ ] 首次进入提示创建管理员账号。
- [ ] 密码少于8位或不同时包含字母、数字时禁止创建。
- [ ] 管理员创建编辑者、审批者、查看者账号。
- [ ] 新用户首次登录必须修改密码。
- [ ] 修改角色或停用账号后，该账号原会话失效。
- [ ] 系统至少保留一个启用的管理员。

## 二、版本审批

- [ ] 编辑者新建交付物和草稿版本。
- [ ] 点击“提交审批”后显示确认窗口，成功后状态变为“审批中”。
- [ ] 审批者可以填写原因后退回草稿。
- [ ] 审批者填写审批意见后发布版本。
- [ ] 新版本发布后，原当前版本自动变为“已替代”。
- [ ] 审批者填写原因后废止已发布或已替代版本。
- [ ] 查看者不显示版本操作按钮。
- [ ] 重复点击或页面数据过期时显示明确错误，不静默失败。

## 三、变更管理

- [ ] 编辑者发起变更。
- [ ] 审批者填写评审意见后批准或驳回。
- [ ] 编辑者将已批准变更置为实施中并提交验证。
- [ ] 审批者确认验证结果后关闭。
- [ ] 各状态只显示当前允许执行的按钮。
- [ ] 操作结果有成功或失败提示。

## 四、CSV导出

- [ ] 交付物台账可选择导出字段。
- [ ] 导出结果遵循关键词、部门、类型、项目、状态、私密等级和分享策略筛选。
- [ ] 变更记录可选择导出字段并遵循状态筛选。
- [ ] Excel打开中文不乱码。
- [ ] 文件名、路径、变更内容含逗号、双引号或换行时单元格未错位。

## 五、关联关系

- [ ] 可以建立派生、验证、依赖、引用、替代关系。
- [ ] 可以选择具体版本，也可以只建立交付物级关系。
- [ ] 详情页同时显示上游和下游关系。
- [ ] 不允许与自身关联。
- [ ] 不允许重复建立相同关系。
- [ ] 编辑者或管理员可以删除关系，查看者和审批者不可删除。

## 六、完整度分析

- [ ] 公共字段缺失可被识别。
- [ ] SWP、PRD、FR、测试用例专属字段缺失可被识别。
- [ ] 建立PRD→FR派生关系后追溯率变化正确。
- [ ] 建立测试用例→FR验证关系后追溯率变化正确。
- [ ] 发布硬件软件包后项目硬件覆盖率变化正确。
- [ ] 待审批、未关闭变更、无当前版本、超90天未更新数量正确。
- [ ] 点击问题清单可进入对应交付物详情。
