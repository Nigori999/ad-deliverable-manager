# 智驾中心交付物管理系统

一个轻量级、单项目部署的交付物管理网页应用：ASP.NET Core 10 同时承载前端静态页面、内部业务路由和 SQLite 数据库访问。

## 当前功能

- 仪表盘：交付物、版本、变更统计和月度趋势，支持查看每项统计口径
- 交付物台账：查询、筛选、录入、详情、可选字段CSV导出和变更时间线
- 交付物分类：硬件软件包、PRD、FR、测试用例
- 版本审批：草稿、审批中、发布、替代、废止
- 三级版本规则：重大版本、功能版本、修订版本，由系统自动计算内部版本号
- 变更审批：待评估、批准/驳回、实施、验证、关闭，并关联变更前后版本
- 交付物关联：派生、验证、依赖、引用、替代，支持交付物级和版本级关联
- 完整度分析：元数据、PRD→FR、FR→测试用例、硬件软件包覆盖和问题清单
- 用户与角色：管理员、编辑者、审批者、查看者
- 用户登录、密码修改、管理员重置密码、账号启停和删除
- 项目/车型基础数据维护
- SQLite 自动建库、启动备份、手动备份和操作日志
- 原生 HTML/CSS/JavaScript，不依赖 Node.js、Vue、React 或在线 CDN

## 版本号规则

内部版本号统一采用`V主版本.次版本.修订号`：

| 版本类型 | 规则 | 示例 |
|---|---|---|
| 重大版本 | 主版本号+1，其他归零 | V1.2.3 → V2.0.0 |
| 功能版本 | 次版本号+1，修订号归零 | V1.2.3 → V1.3.0 |
| 修订版本 | 修订号+1 | V1.2.3 → V1.2.4 |

首个版本固定为`V1.0.0`。后续用户只选择版本类型，系统扫描该交付物现有合法版本并自动计算新版本号，提交时由后端再次校验。

## 变更闭环

```text
发起变更（自动锁定当前版本）
→ 审批通过
→ 开始实施
→ 创建并关联变更版本
→ 变更版本提交审批并正式发布
→ 提交验证
→ 确认关闭
```

系统不直接覆盖历史版本。变更后版本正式发布时会成为交付物当前有效版本，原当前版本自动标记为已替代。未创建变更版本不能提交验证，变更版本未发布不能关闭变更。

## 角色权限

| 角色 | 主要权限 |
|---|---|
| 管理员 | 所有功能、用户管理、备份和审计日志 |
| 编辑者 | 新增和维护交付物、版本、关联关系，发起并实施变更 |
| 审批者 | 退回或发布版本，批准、驳回和关闭变更 |
| 查看者 | 查询、查看统计和导出CSV |

管理员同时具备编辑者和审批者的业务能力。

## 技术结构

```text
ASP.NET Core 10 单项目
├─ wwwroot：HTML / CSS / JavaScript
├─ Controllers：仅供本网页使用的内部业务路由
├─ Services：SQLite访问、版本规则、用户、导出和备份
├─ Security：密码散列、角色和用户声明
├─ Data/schema.sql：幂等建表及基础数据初始化
└─ data/deliverables.db：运行后自动生成
```

项目不启用 Swagger，也不规划对外开放 API。`/internal/*` 路由只用于本系统网页和后端之间的数据交互。

## 首次运行和升级

首次运行新版程序时：

1. 系统自动创建或升级SQLite表结构，不删除原有交付物数据。
2. 如果数据库中还没有用户，页面会要求创建第一个管理员账号。
3. 密码至少8位，并同时包含字母和数字。
4. 管理员创建其他用户时，可要求用户首次登录后修改密码。

建议升级前保留现有`data/deliverables.db`备份。程序启动时也会自动生成一份SQLite在线备份。

## 开发运行

前提：开发电脑安装 .NET 10 SDK。

```bash
dotnet restore
dotnet run
```

默认访问：`http://localhost:5078`

## 发布 Windows 64 位免运行时版本

双击：

```text
publish-win-x64.bat
```

或执行：

```bash
dotnet publish -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true \
  -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:PublishTrimmed=false \
  -o publish/win-x64
```

发布目录中的程序包含 .NET 运行时。同事无需安装 .NET、SQLite、IIS、Node.js 或数据库软件。

## 运行模式

### 单机模式

保持`appsettings.json`：

```json
"AllowLanAccess": false
```

双击`AdDeliverableManager.exe`或`start.bat`。

### 局域网共享模式

在指定主机上修改：

```json
"AllowLanAccess": true
```

其他同事通过以下地址访问：

```text
http://主机IP:5078
```

还需在Windows防火墙中允许TCP 5078端口。SQLite数据库必须保留在运行后端的电脑本地磁盘，不要把`.db`文件放到网络共享目录供多台电脑直接打开。

## 数据与文件

- 实际软件包、PRD、FR、测试用例继续存放在文件服务器。
- SQLite只保存元数据、版本、关联、变更、账号和审计信息。
- CSV导出使用UTF-8 BOM，可直接用Excel打开。
- `data/*.db`、密钥、备份和日志默认不提交到Git。
- 错误日志写入`logs/error-yyyyMM.log`。

## 当前边界

- 不在网页中上传或下载大型交付物文件，只记录服务器路径。
- 角色权限采用四种固定角色，不提供自定义权限编排。
- 完整度统计中的硬件覆盖采用当前内置的标准硬件类别，后续可扩展为按项目配置应交付清单。
- 数据库升级使用幂等SQL，不依赖EF Core Migration。
